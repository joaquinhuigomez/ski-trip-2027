# 雪旅 · Alps Ski Trip 2027

Proposal-and-vote page for a group ski week, last week of January 2027. It compares Val Thorens (3 Vallées), the Stubai valley (Tyrol) and Les Arcs 1800, with costs, and has a live vote.

- `index.html`: the page (plain HTML/CSS/JS, no build step)
- `data.js`: all prices, listings and decisions. Edit this to update numbers.
- `images.js`: photo manifest (Unsplash License / Wikimedia Commons, credited in the footer)
- `backend/Code.gs`: Google Apps Script vote API (stores ballots in a Google Sheet)

Prices checked 4 Oct 2026; re-check the linked sources before paying.
